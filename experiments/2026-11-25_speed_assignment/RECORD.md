# 固定路徑上的速度分配，自己寫的最佳化器

日期：2026-11-25
程式：`run.py`
結果：`results/run_all.txt`（10 條賽道）、`results/test_banded0.txt`、`results/track<k>.npz`

## 目的

使用者：把問題拆開。給一條夠平滑的路徑，在上面決定 dp/dt；機頭是輸入；最佳化器自己寫，可以用自動微分。

## 方法

- 路徑：已存的 CPC 圈，5 次 B-spline，0.5 m。只是測試用的路徑，方法不依賴它從哪裡來。
- 機頭：固定的水平方向 h，選成離起點所有推力方向都最遠的方向，避開奇異點（"heading margin"）。機身偏航角速度為 0。
- 速度：q(u) = u′²，週期 4 次 B-spline，節點 1 m。
- 目標：∫du/√q。限制：每個取樣點每顆馬達推力在 [T_min, T_max]，|w_x|、|w_y| ≤ 15（平坦性精確推導），q 的控制點 ≥ eps。
- 最佳化器：augmented Lagrangian（PHR）處理不等式，內迴圈用阻尼 Newton（T 的精確 Hessian、限制項用 Gauss-Newton）+ Armijo。每個取樣點只牽動附近 5 個節點，矩陣是帶狀的（banded 版本由分出去的 agent 寫）。IPOPT 只拿來對答案。

- 賽道 4、5：自己的最佳化器停在很差的地方（4.66 vs 4.06、14.13 vs 7.39）。

## 觀察

1. 固定的機頭方向是保守而且危險的：側翻時會碰到奇異點。使用者後來說「機頭方向應該是 input 吧」，之後改成機頭當變數，再改成不管機頭。
2. 這裡的限制還是用除以總推力的平坦性公式，取樣點之間沒有保證。
