# 完美迷宮上的三種方法

日期：2026-11-24
程式：`run.py`。迷宮在 `../common/bench.py` 的 `perfect_maze`；三種方法直接從各自的實驗目錄載入。
結果：`results/run.log`，以及 `results/<方法>/maze<k>.png`、`maze<k>.npz`。

```bash
cd experiments/2026-11-24_perfect_maze
uv run --with casadi --with pyyaml --with scipy --with numba --with matplotlib python run.py
```

## 目的

隨機半徑的柱子網格太容易走：只有約 9% 的空隙被堵住，路線幾個彎就到了。使用者看過樣本後，選擇改用「完美迷宮」，在比較複雜的迷宮上重新比較這幾種方法。

## 迷宮

- **網格：** 8×6 個點，間距 5 m，圍出 7×5 個格子。網格範圍 x = 10–45 m、y = 0–25 m。
- **牆：** 相鄰格點之間的牆，厚 0.5 m，當作線段加 0.25 m 半徑的膠囊形障礙物。
- **完美迷宮：** 用隨機深度優先搜尋把牆打通，任兩格之間剛好只有一條路。亂數種子就是迷宮編號 0–4。
- **門和起終點：**
  - 外圈封閉，只在左邊和右邊各開一個門，門開在隨機的一排。
  - 起點在左門外 x = 3 m 處，終點在右門外 x = 52 m 處。
  - 地圖高度等於網格高度，所以沒辦法從迷宮外面繞過去。
- **其他設定跟前面的實驗相同：** CLEAR 0.5 m、機身半徑 0.25 m、定高 2 m、單程不停、起點速度 1 m/s、最高速度 15 m/s。

`bench.py` 的修改：障礙物改用膠囊形表示，舊的圓柱就是長度為零的膠囊，所以舊實驗的結果不變。佔用格、最近距離、畫圖都支援兩種形狀；`save`、`load` 可以指定目錄。

## 方法

- **沒跑彈性帶：** 它需要好幾條手動加的限制，之前已經決定不再往下調。
- **基準：** `../2026-11-24_baseline_corridor_smooth` 的 `plan`，沒有修改。
- **走廊 + min-snap：** `../2026-11-24_corridor_minsnap` 的 `minsnap`。
  - 走廊的建法相同。原本是取每根柱子圓心到線段的最近點；牆是線段，所以改成取「牆的中心線段」和「路徑線段」之間的最近點對，在那裡畫切線。
  - 對圓柱來說，結果跟原本一樣。
- **最小曲率：** `../2026-11-24_min_curvature` 的 `min_curv`。
  - 原本沿法線的邊界是用跟圓求交點的公式算的。這裡改成沿法線每 0.02 m 取樣，看哪些點離牆夠遠，取包含 α = 0 的那一段可行區間。
  - 彎道內側的上限照舊：|α| 不超過相鄰法線交會半徑的 0.8 倍。

## 觀察

1. **迷宮 2 太簡單。** 門的位置剛好讓路線幾乎是直的，三種方法都是 3.75 s 左右，比不出差別。這是隨機門的副作用。
2. **min-snap 和最小曲率都比基準快很多。** 在有彎的 4 張迷宮上快 5–27%。
3. **在有 U 形迴轉的迷宮上（3、4），最小曲率輸給 min-snap。**
   - 原因：最小化 ∫k² 會把整條走道的寬度都用上，在每個迴轉繞最大的弧。迷宮 3 的路徑長因此到 111.5 m，比 min-snap 多 8 m。
   - 曲率確實比較小，但多出來的距離抵掉了速度的好處。
   - 這就是之前說的「最小曲率不等於最短時間」：在柱子迷宮上不明顯，在連續急彎的迷宮上就看得出來。
   - min-snap 的目標裡有時間項，會自己在「繞大弧」和「走短一點」之間取捨。
4. **在迴轉較少的迷宮 0、1，最小曲率還是最快。**
5. **安全距離：**
   - min-snap 是 0.50–0.54 m，守住 CLEAR。
   - 最小曲率擬合後是 0.47–0.50 m，少 3 cm。
   - 基準在迷宮 0 只剩 0.46 m，其他迷宮比較寬鬆。
6. **基準的終點誤差**一樣是約 0.5 m（終點沒有硬性固定），而且轉彎數 7–8，最慢。
7. **傻瓜程度：**
   - 最小曲率每輪最佳化不到 0.1 s，沒有參數要調。
   - min-snap 在長迷宮上很慢（最多 133 s），而且 5 張裡有 3 張要用備案。

## 還沒做的

- 曲率加長度的混合目標，例如最小化 ∫k² + λL，看能不能在 U 形迴轉的迷宮上贏過 min-snap。不過這會多一個權重 λ。
- 讓 min-snap 的時間分配變快、變穩（MINCO）。
- 門的位置改成固定在對角，避免出現像迷宮 2 那樣太簡單的情況。
- 最小曲率的邊界多留 3 cm，吸收擬合誤差。
