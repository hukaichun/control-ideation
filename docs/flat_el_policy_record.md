# 平坦 E-L 控制律：完整記錄

日期：2026-11-22
程式：`examples/`；資料：`logs/`；模擬：完整四旋翼模型（UZH `rpg_time_optimal` 的 quad.yaml：m = 0.85 kg、臂長 0.15 m、推重比 3.3、ω_xy ≤ 15 rad/s、ω_z ≤ 0.3 rad/s）。

---

## 1. 目標與硬條件

- **應用**：盡快到達目的地。事前規劃路徑避開已知障礙物，途中突發的障礙物用補的處理，不重算。
- **硬條件**：
  - u = u(x)，只看當下狀態，不顯含時間；
  - 控制律由一個 Lagrangian L 經 E-L 方程加阻尼得到；
  - 無人機動態要寫在 L 裡；
  - 天然穩定；
  - 不分內外層；
  - 不用質點；
  - 不用最近點；
  - 各項都是解析的。
- **規劃**：
  - 給定路徑時，找出滿足無人機動態的最佳速度；
  - 給定任意門時，要能快速找出合理的路徑；
  - 機體極限由規劃事先留餘量處理。
- **路徑**：只用直線和圓兩種隱函數拼接。接頭處的不平滑交給控制律自己修正。

## 2. 設計（已與使用者確認）

### 2.1 無人機的平坦動力方程

原始模型（馬達瞬間反應）：

```
ṗ = v,   v̇ = c z − g e₃,   ż = ω × z,   J ω̇ = τ − ω × Jω
狀態 (p, v, R, ω)，輸入 c（推力/質量）、τ（力矩）
```

- 沿推力方向是二階：c 直接出現在 v̇。
- 垂直推力方向是四階：τ → ω → z → p̈。

**動態延伸**：把 c、ċ 也算成狀態，輸入改成 c̈。平坦系統就成了

```
狀態 x = (p, v, a, j) ⟷ (p, v, R, ω, c, ċ)（c > 0 時一一對應），輸入 w = snap
ṗ = v,  v̇ = a,  ȧ = j,  j̇ = w
c̈ = z·w + c|ω × z|²；ω̇⊥ 由 w⊥ 解出；τ = Jω̇ + ω × Jω；馬達推力 = M_x⁻¹[T, τ]
```

### 2.2 E-L 方程

```
L = L(p, v, a)
L_p − d/dt L_v + d²/dt² L_a = Q(p, v, a, j)
d/dt = D + w·∂_j，   D = v·∂_p + a·∂_v + j·∂_a，   M = L_aa
⇒ w = M⁻¹ [ Q − L_p + D L_v − D(D L_a) ]      （D(D L_a) 取不含 w 的部分）
```

**條件**：
- M 可逆；
- 規劃的飛行滿足 E-L 方程，且 Q 在飛行上為 0；
- Q 必須含 j，才能漸近收斂。理由：Q 不含 j 時，相空間體積繞一圈不變（Liouville 論證）。

### 2.3 L 與 Q

- **路徑**：每一段是兩個隱函數 φ = 0。
  - 直線：φ = (n₁·(p − a), n₂·(p − a))
  - 圓：φ = (n·(p − c), (|p − c|² − R²)/(2R))
- **速度**：能量 H = ½|v|² + V(p)。飛行上 H = H*，所以速度 = √(2(H* − V))。速度規劃的自由度全部放在 V。

```
μ = v̂·(a + ∇V)                         （Ḣ = |v| μ）
L = ½|φ̈|² − 3ω_φ²|φ̇|² + ½ω_φ⁴|φ|² + ½μ²
Q = ∇φᵀ(−4ω_φ φ⃛ − 4ω_φ³ φ̇) + v̂ [ −3ω_H μ̇ − (3ω_H² − V_tt) μ − ω_H³ (H − H*)/|v| ]
```

- 側向偏離的極點：(λ + ω_φ)⁴；能量誤差的極點：(λ + ω_H)³。
- 能量誤差的回饋放在 Q 裡，不在 L 裡。它在飛行上為 0，也含 j（透過 μ̇）。
- 所有導數都由 CasADi 符號式精確計算，沒有數值差分、沒有最近點、沒有迭代。
- 每一點屬於哪一段，由該段的範圍判斷：直線看是否在兩端之間，圓看角度。範圍在接頭平面上銜接。只有在離路徑比圓半徑還遠、幾段範圍重疊時，才挑 |d| 最小的那段（`path_pieces.piece_index`）。

### 2.4 c、ċ 的來源（兩種都做）

- **A**：控制器自己積分 c、ċ（控制器有記憶，看不到馬達被截斷）。
- **B**：模擬裡讓總推力有自己的動態 c̈ = 輸入，c、ċ 由機體提供（`flat_el_policy.ThrustPlant`）。

### 2.5 只為實驗做的選擇（不是使用者的設計）

- **V 的函數空間**：使用者不接受用這種方式固定 V 的函數空間，只同意先拿來做實驗。
  - 直線上是 u·(p − a)/len 的 6 次多項式；
  - 圓上是 1、Re zᵏ/rᵏ、Im zᵏ/rᵏ（k ≤ 6，z = x + iy），也就是不算角度的 cos kθ、sin kθ；
  - 用加權最小平方擬合 V = H* − ½σ²，兩端加大權重讓接頭連續，再加 0.3 的正則化。
- **極點的數值**：ω_φ、ω_H。

## 3. 規劃

### 3.1 路徑（直線 + 圓）

`path_g2.fast_plan_g2_fit(gates, frac, q=0, offset)`：
- 每個門放一個轉角點，轉角點之間用直線連起來，每個轉角放一段與兩邊直線相切的圓弧；
- 圓弧大小由 frac 決定，UZH 用 0.95；
- 圓弧沿轉角滑動，讓門落在路徑內側 0.24 m（容許範圍 0.3 m）；
- 耗時 0.065 s。

### 3.2 速度最佳化（`speed_opt.optimise`）

- **變數**：σ(s) 是 150 個控制點的週期三次 B-spline，飛行用的也是同一條曲線。
- **目標**：總時間 + λ∫|j|² dt，λ = 10⁻⁶。
- **限制**：每 12 cm 用精確導數檢查一次，a、j、snap 由平坦性從路徑和 σ 算出：
  - 推力下限 |a + g| ≥ 2 m/s²；
  - 機身轉速 |j⊥|/c ≤ 0.9 × 15 rad/s；
  - 推力，二選一：
    - 舊版：|a + g| ≤ 比例 × 最大推力；
    - **先保力矩版（`motor=`）**：從 snap 算出 α⊥ = z × z̈、|τ| = I_x|α⊥|，對任意偏航角都成立（最壞方向係數 √2）：
      ```
      T + √2|τ|/l ≤ 4·餘量·Tmax,     T − √2|τ|/l ≥ 4·Tmin
      ```
- **接頭**：曲率的跳動先不管（`use_kd=False`），由控制律修正。
- **起始值**：TOPP 加 2 m 平滑。
- **時間**：建立問題 1.65 s（只需建一次，可重複使用，還沒做），求解約 0.15 s（舊版）或 0.8–0.9 s（先保力矩版）。

### 3.3 V 擬合與控制律建立

- 控制律建立 0.04 s；
- 每一步計算 0.055 ms（Python 呼叫 CasADi）。

## 4. 實驗結果

### 4.1 直線偏移測試

長直線、5 m/s，從側向、垂直、斜向偏 0.5–0.7 m 出發：約 1 s 收斂到 0，速度回到 5 m/s。A、B 結果相同。

### 4.2 能量項單獨測試

長直線，速度沿路以 ±1、±2 m/s 正弦變化，起始速度 +0.5 m/s：能量誤差約 2 s 收斂到 0。

### 4.3 矩形測試（直線 3 m + 四個 90° 圓弧，等速）

修好能量項之後，只重跑了 R = 4 m、σ = 10 m/s 這組（圓弧要用約 83% 推力，ω_φ = 8、ω_H = 4）：
- A、B 都飛完三圈，沒有發散；
- 每個接頭偏離 0.3–0.5 m，高度最多掉 0.15 m。

偏移的節奏：
- **進入圓弧**：轉身延遲，往外偏，到圓弧中段最大 +0.49 m；
- **圓弧後半**：修得慢，因為收斂時間約等於整段圓弧的飛行時間；
- **進入直線**：修過頭，約 0.15 s 越過路徑，到直線末端停在內側約 −0.2 m；
- 每一圈都重複這個循環。

其他 R、σ 組合是在修好能量項之前跑的，結果作廢，還沒重跑。

### 4.5 基準

**CPC**（自製，完整模型，`quad_time_optimal.py`）
- UZH 6.129 s，求解 26 s；
- 20 條賽道求解時間中位數 38 s，最長 73 s（`logs/cpc_benchmark.csv`）。

**PX4 預設控制器**（`px4_baseline.py`）

照 fork（v1.17）原始碼移植 PositionControl、AttitudeControl、rate_control 的預設參數。用 offboard 方式追 CPC 軌跡（位置、速度、加速度前饋、偏航）。

- 要放慢 3.5 倍（一圈 21.45 s），門才在 0.30 m 內；
- 放慢 3 倍（18.39 s）時門偏 0.57 m；
- 把限制放寬到機體極限，結果幾乎一樣，因為姿態增益 P = 4 把轉速壓在約 5 rad/s；
- 角速度環的增益改成固定頻寬 40 rad/s，因為原本的增益是依機體調的。

**CPC 式速度規劃**（`speed_cpc.py`，完整模型 + 路徑管子 δ = 0.15 m）
- 修掉兩個漏洞：節點之間抄捷徑（改成沿路徑固定間距放節點）、四元數長度沒鎖住；
- 到 6.76 s 時仍未收斂（1500 次迭代、195 s），還沒拿去飛。

## 5. 過程中的錯誤與修正

1. **偷換設計**（已全部刪除）：
   - 質點 f 加上 L = ½|a − f|²，形成內外層；
   - 最近點投影，卻稱為「解析投影」；
   - s/d 管子座標；
   - 數值差分。

   這些版本的程式和資料都已刪除，清單見第 7 節。
2. **直接寫的四階 L 卻用了原始系統**：推力方向只有二階，控制律在那個方向沒有回饋，飛機以 0.35 m/s 往下掉。改用動態延伸的平坦系統後解決。
3. **能量項沒推導就照抄係數**：能量誤差在第一段直線上就漂走。改成照推導的 μ 形式後解決。
4. **實驗用 V 離開路徑後暴增**：圓上用 x、y 的一般多項式會產生互相抵消的大係數，偏 3 cm 能量就跳 +1320。改成除以 rᵏ 的調和函數並加正則化後解決。
5. **矩形「發散」的錯誤解釋**：我原本推測是推力用滿、沒有餘力修正，其實是第 3 點的能量項錯誤造成的。
